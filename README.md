# OPPO Watch 2 专享全彩常亮表盘 (WatchFace)

专为 **OPPO Watch 2** 及同类智能手表量身打造的 Android 全彩 AMOLED 常亮表盘应用。支持自定义壁纸、双击切图、多模式定时轮换、微像素级防烧屏偏移、动态光感调光以及手表屏幕全尺寸自适应排版。

---

## 🌟 核心功能特性

### 1. 🖼️ 全彩高清壁纸与自定义导入
- **内置 5 款精选 AMOLED 预设壁纸**：深空星云、极光夜空、暮色沙丘、暗晶多面、赛博霓虹。
- **自定义本地壁纸导入**：
  - 自动扫描手表内部存储路径：`/sdcard/WatchFace` 与 `/sdcard/Pictures/WatchFace`。
  - 支持 `.jpg`、`.jpeg`、`.png`、`.webp` 等常见图片格式。
  - 采用亚采样与硬件位图加载技术，无内存泄漏与 GC 顿挫。
- **平滑淡入淡出动画 (Crossfade)**：切换壁纸时具备 350ms GPU 硬件加速交叉渐变，视觉体验丝滑。

### 2. 🔄 智能壁纸轮换策略
- **双击即时切图 (Double Tap)**：随时双击表盘屏幕中央快速切换下一张壁纸。
- **抬腕唤醒轮换 (On Wake)**：每次亮屏时自动切换下一张，带来每次抬手都有新视觉的惊喜感。
- **15 分钟定时轮换 (15 Minutes)**：每 15 分钟平滑更换壁纸。
- **整点轮换 (Hourly)**：每到整点时触发壁纸轮换。
- **固定壁纸模式 (Fixed)**：在控制中心锁定喜爱的一张壁纸不进行自动轮换。

### 3. 🛡️ AMOLED 防烧屏与暗光保护 (Burn-In Guard)
- **微像素轨道偏移**：进入熄屏常亮（DIM）状态后，每分钟自动在 `[-8px, +8px]` 范围内沿环形轨道微调时间与文字位置，杜绝长期静止导致的像素老化。
- **高对比度文字阴影**：时间与日期采用双层大模糊扩散阴影，即使在纯白或复杂高杂色背景下依然清晰易读。

### 4. 💡 智能光感与低功耗传感器调度
- **自适应环境光调光**：内置 5 级环境光照迟滞算法（Hysteresis），暗室柔和不刺眼、户外强光清晰可见。
- **DIM 状态低功耗优化**：熄屏状态下自动挂起高频光线传感器，仅保留姿态解算，大幅延长手表待机续航。

### 5. ⌚ 手表窄屏自适应排版
- **单行居中排版**：采用容器动态测算字体尺寸（`BoxWithConstraints`），时间与日期绝对单行显示、杜绝折行与超宽被切。
- **纯净电量显示**：底部极简电量百分比展示，无多余元素干扰。

## 👆 手势交互指南

| 手势 | 功能说明 |
| :--- | :--- |
| **双击屏幕** (Double Tap) | 立即切换至下一张壁纸 (支持平滑淡入) |
| **长按屏幕** (Long Press) | 调出表盘控制中心抽屉面板 (可自定义模式、超时、管理壁纸) |
| **轻触屏幕** (Single Tap) | 从 DIM 熄屏状态唤醒至 ACTIVE 亮屏状态 |

## 📂 自定义壁纸放置方法

1. 将智能手表通过数据线连接至电脑，或使用手表端文件管理器/局域网互传应用。
2. 在手表内部存储根目录下新建文件夹：
   ```
   /sdcard/WatchFace
   ```
3. 将您喜欢的图片放入该文件夹即可，表盘会自动加载并在双击或轮换时展示。

## 🛠️ 技术栈与架构

- **语言**：Kotlin 100%
- **UI 框架**：Jetpack Compose (Material 3)
- **架构模式**：MVVM (StateFlow + Coroutines)
- **持久化**：SharedPreferences (自动保存用户配置)
- **传感器**：SensorManager (Light Sensor + Accelerometer)
- **图形渲染**：Android Bitmap 硬件解码 + Canvas / Crossfade Transitions

## 🔑 GitHub Actions 持续集成与固定签名说明

为方便在手表上**直接覆盖更新安装**（避免出现 `签名不一致` 导致必须先卸载再安装），本项目的 GitHub Actions 自动化编译流程已固定使用统一签名：

- **固化签名密钥**：项目中已内置固化的 Release 签名密钥（`release.keystore.base64`），每次 GitHub 触发编译打包生成的 Release APK 均具备**完全一致的数字签名证书**。
- **平滑无缝覆盖安装**：后续更新或编译新版本时，直接在手表上安装新 APK 即可无缝覆盖升级，历史设置和配置完美保留。
- **自定义私有密钥（可选）**：如果您希望使用自己的私有证书，可在 GitHub 仓库的 `Settings -> Secrets and variables -> Actions` 中配置 `KEYSTORE_BASE64`、`STORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD`，CI 工作流会自动优先使用您的私有秘钥。
